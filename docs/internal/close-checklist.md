# Build close checklist

Internal. Run at handoff for every platform or lead-system build. Watch and Build block stay off the public offers page; sell them here.

## Before invoice close

- [ ] Operator handoff delivered (how to run the system without Wayalabs)
- [ ] Data boundary restated in the handoff note
- [ ] Discovery credit line applied when the 60-day rule applies (`offer-kit.md`)

## Recurring (default ask)

- [ ] Offer **Watch** at $400 / month — monitoring and small fixes
- [ ] Offer **Build block** at $1,200 / month if they want scheduled feature work
- [ ] Target: live client on Watch within 30 days of handoff

## Do not

- Sell agent pilots or orchestrators
- Invent a new SKU at close
- Leave recurring unmentioned because “they might ask later”

## Capacity

If concurrent builds are at the cap, do not open another build at close. See `capacity.md`.
