# Platform kit

Internal. Productized shape for the Platform build offer ($10,000–$18,000). Customize brand, content model, and handoff — not a greenfield stack every time.

Proof reference: Queen City Soundboard (`queencitysoundboard.com`). Secondary pattern: Urban Stone public site layer.

## Fixed shape

1. **Public site** — Next.js on Vercel (or the stack named in the brief)
2. **Forms** — visitor intake that emails the operator
3. **Data store** — records the operator keeps (e.g. Supabase)
4. **Handoff** — operator can publish/update without Wayalabs in the loop

## Discovery inputs required

- Outcome and audience
- Pages and content model in scope
- Forms and where submissions go
- What lives in the data store vs static content
- SEO / schema requirements that matter for this business
- Languages or locales if required

## Delivery checklist

- [ ] Site live with agreed pages
- [ ] Forms deliver to email (and store if in scope)
- [ ] Operator handoff doc: how to edit content and review submissions
- [ ] Sitemap, basic SEO, and share image agreed in the brief
- [ ] Close with Watch invitation (see `close-checklist.md`)

## Pricing band

Price inside $10,000–$18,000 by page count, content model depth, and integrations — keep the four fixed shape items.
