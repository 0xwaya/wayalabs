# Funnel metrics

Internal. Track these each week. Phase 1 of the scale-up plan.

| Metric | Source | Target |
|---|---|---|
| Discovery calls booked | Cal.com | Rising week over week |
| Contact form submits by intent | Resend / contact logs (intent only) | discovery + lead-system dominate |
| Discovery deposits paid | Invoices | 4–6 / quarter |
| Discovery → build close rate | Deposits → build invoices | ≥50% |
| Live clients on Watch | Invoices | All live clients within 30 days of handoff |
| Active concurrent builds | Delivery board | Cap at 2–3 |

Do not invent vanity metrics (site visits alone, agent demos). Conversion and retainers are the scale signal.
