# WayaLabs offer kit

Internal. The public page is [/offers](https://wayalabs.com/offers). It shows discovery, the platform build, and the lead system. Watch, the build block, and agent pilots stay here.

Updated 3 November 2026. The 40% first-invoice discount is retired. These are the prices. Not booked revenue.

## Rules

- One discovery price. There is no list price and no percent-off.
- Discovery is the first week. It ends in a written brief and a go or no-go.
- If a platform or lead-system build starts within 60 days, the discovery amount paid is credited on that invoice.
- The credit applies once, to that build.
- Watch and the build block are not on the public page.
- Agent pilots are not for sale. Echo stays in the private network.
- A predecessor organization that already paid for that discovery does not get the credit again.
