## Urban Stone Collective

Repo: `0xwaya/urbanstone`. Live: https://urbanstone.co

What the repo actually is today:

- Next.js 15 Pages router, React 19, Supabase, Resend, Vercel.
- Quote form and the Onyx chat both hand leads to the sales webhook.
- Contractor portal uses magic links.
- Lead-sourcer runs from GitHub Actions. Hamilton and Butler permit sources, and Facebook Marketplace via Apify, stay off unless a repo flag enables them. Reports are per source, with spend caps. This is not unsupervised outreach.
- Social images for 29 October were committed in the repo. Nothing in the app posts them.

The public README used to describe the tree as a snapshot with no lead destination. As of this review it points at urbanstone.co and says October lead-sourcer sources stay opt-in. The rest of that README is still the snapshot runbook, not a claim that every gap is closed in production.

Next step, native to this repo: a publisher inside the Urban Stone backend for its own social images, and lead-sourcer sources remaining opt-in until someone reviews lead quality.
