## Urban Stone Collective

Repo: `0xwaya/urbanstone`. Live: https://urbanstone.co

What the repo actually is today:

- Next.js 15 Pages router, React 19, Supabase, Resend, Vercel.
- Quote form and the Onyx chat both hand leads to the sales webhook. Onyx calls the OpenAI API with the Urban Stone playbook and falls back to the on-site knowledge base if that call fails.
- Contractor portal uses magic links.
- Lead-sourcer runs unattended from GitHub Actions at 8:00, 12:00, and 5:00 ET. The scheduled job is in live mode and delivers matched leads to the sales inbox. It does not contact the people who posted.
- Social images are committed in the repo. Nothing in the app posts them.

The public README points at urbanstone.co. The lead-sourcer is an unattended scheduled job in live mode. The rest of that README is still the snapshot runbook.

Next step, native to this repo: a publisher inside the Urban Stone backend for its own social images. The lead-sourcer already runs unattended.
